# Mealz documentation

Mealz is a personal recipe book and weekly dinner planner. It is published as a static [Hugo](https://gohugo.io) site on GitHub Pages: https://zachary-povey.github.io/mealz/

| Doc | Read it when you need to… |
| --- | --- |
| [vision/README.md](vision/README.md) | Understand what the app is for. This is the product spec, written by the owner. |
| [architecture.md](architecture.md) | Get the big picture: components, how data flows, repo layout and why it is built this way. |
| [content.md](content.md) | Read or write recipes, meal plans or the files in `data/`. |
| [meal-planner.md](meal-planner.md) | Change or operate the weekly dinner planner (Python and GitHub Actions). |
| [website.md](website.md) | Change the Hugo templates, pages, client-side JavaScript or styling. |
| [development.md](development.md) | Set up locally, run tests, build the site, deploy, and avoid known pitfalls. |

If you're new, read them in this order: vision, architecture, development, then the doc for the area you're changing.
